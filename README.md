# 📊 GitHub Stats & Activity Card

A sleek, lightweight, client-side web application built with vanilla HTML, CSS, and JavaScript that fetches and displays GitHub user profiles and core statistics instantly.

## ✨ Features

* **🔍 Instant Profile Lookup:** Search for any public GitHub username in real-time with smooth responsiveness.
* **🎨 GitHub Dark UI:** Carefully crafted styling to seamlessly match GitHub's modern dark interface.
* **📈 Key Metrics Display:** View public repositories, follower and following counts, bios, and locations at a glance.
* **⚡ 100% Client-Side:** No backend setup required; runs completely in the browser leveraging the public GitHub REST API.
